# Disabled maps

This directory holds the upstream maps that are deliberately excluded from Pudgywars. The game enumerates normal local-match maps only from `data/maps/`, so these files remain available for maintenance without returning to the selection menu.

The active pool is limited to ice-, snow-, winter-, and frozen-themed maps. `data/worlds/` contains a single Ice Festival world entry so the native world loader remains satisfied without exposing non-ice content.
