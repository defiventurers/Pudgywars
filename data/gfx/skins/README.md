# Pudgywars player skins

This directory is intentionally limited to four playable character sheets: `pudhy_Polly.png`, `pudhy_Retsba.png`, `pudhy_Pengu.png`, and `pudhy_Abster.png`.

Every sheet is a 192 × 32 PNG comprising six left-to-right 32 × 32 frames: idle, walk A, walk B, jump, flattened defeat, and airborne defeat. Magenta (`#FF00FF`) is the transparent colour key. Preserve these dimensions and frame positions when editing a skin.

The upstream skin collection is stored in `../skins-original/` and is not enumerated by the game.
